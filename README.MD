## 🚀 시작하기 (Getting Started)

프로젝트를 로컬 환경에 설치하고 실행하는 방법입니다.

### 요구 사항 (Prerequisites)

*   Node.js 18.x 이상
*   Python 3.10 이상

### 설치 및 실행 (Installation & Running)

1.  **레포지토리 클론**
    ```bash
    git clone https://github.com
    cd project-name
    ```

2.  **백엔드 설정 및 실행**
    ```bash
    cd backend
    pip install -r requirements.txt
    uvicorn main:app --reload
    ```

3.  **프론트엔드 설정 및 실행**
    ```bash
    cd ../frontend
    npm install
    npm run dev
    ```
